## wazuh-soc-lab
🛡 Wazuh SIEM SOC Home Lab

This project demonstrates hands-on experience using the open-source SIEM platform Wazuh to simulate real-world Security Operations Center (SOC) activities.

🔬 Lab Overview

In this lab, I configured and tested the following security monitoring capabilities:

✅ File Integrity Monitoring (FIM)

✅ SSH Brute Force Detection

✅ Vulnerability Scanning

✅ Custom Rule Creation

🚧 This lab is continuously updated with new attack simulations and detections.

The goal was to simulate attack detection, log monitoring, and security alert generation in a controlled home lab environment.

🖥 Lab Environment

Ubuntu Server (Wazuh Manager)

Wazuh Dashboard

Virtual Machine environment

Private IP addressing for security

📂 Project Breakdown
🔎 1. File Integrity Monitoring (FIM)

Monitored sensitive system files such as /etc/passwd and triggered alerts when changes occurred.

🔐 2. SSH Brute Force Detection

Simulated repeated failed login attempts and observed Wazuh detection alerts.

🛡 3. Vulnerability Scanning

Enabled the vulnerability detection module to identify installed packages with known CVEs.

⚙ 4. Custom Rule Detection

Created a custom rule in local_rules.xml and successfully triggered a custom alert.
