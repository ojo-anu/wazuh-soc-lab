# Nmap Scan Detection with Wazuh

## Overview
This project demonstrates how Wazuh detects suspicious activity generated by a network scan using Nmap.

An attacker machine (Kali Linux) performed a reconnaissance scan against an Ubuntu server monitored by the Wazuh agent. The scan generated abnormal web requests which triggered Nginx error alerts in Wazuh.

## Lab Environment
Wazuh Manager: Wazuh SIEM running on a virtual machine  
Monitored Endpoint: Ubuntu Server with Wazuh agent installed  
Attacker Machine: Kali Linux  
Network: VirtualBox internal network

## Attack Simulation
The following Nmap scan was executed from the attacker machine:

nmap -sS <server-ip>
nmap -A <server-ip>

The scan probed multiple ports and services on the monitored Ubuntu server.

## Detection
Wazuh analyzed the server logs and generated alerts from the Nginx web server logs.

Example alerts detected:

Rule ID 31120 – Web server 500 error code  
Rule ID 31301 – Nginx error log detected

These alerts were triggered due to abnormal HTTP requests generated during the scan.

## Investigation
The Wazuh dashboard showed the alerts with the source IP address of the attacker and the affected server.

This demonstrates how reconnaissance activity can generate detectable anomalies in service logs.
